# ImPuls Minecraft

Основной репозиторий Minecraft-сервера **ImPuls**.

## Хостинг
- MineKeep
- Java: `impuls.minekeep.gg`
- Bedrock: `impuls.bedrock.minekeep.gg`

## Назначение репозитория
Здесь хранятся исходники и версии конфигурации сервера ImPuls: datapacks, конфигурации, документация и файлы сборки, которые можно безопасно версионировать в Git.

> Мир (`world/`), логи, кэши и другие динамические/тяжёлые runtime-файлы не должны храниться в Git.

## Развёртывание на MineKeep
MineKeep предоставляет файловый менеджер для загрузки серверных файлов. Репозиторий является источником актуальной сборки, а рабочая копия разворачивается на MineKeep.

## Структура
- `datapacks/` — datapacks ImPuls
- `config/` — версионируемые конфигурации
- `docs/` — документация
- `.github/` — автоматизация GitHub
