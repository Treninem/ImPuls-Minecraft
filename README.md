# ImPuls Minecraft Server

Кроссплатформенный Survival + RPG сервер **ImPuls** для Paper 1.21.11: экономика, гильдии, войны, ранги, задания, подземелья, защищённая столица, земля игроков, VIP-механики, городские ивенты, исследование регионов и 32 физических ворот.

## Текущий релиз: v1.2.0

GitHub Actions собирает и проверяет:

- `ImPulsCore-1.2.0.jar` — Java/Paper ядро;
- `ImPulsCore_Datapack_v1.2.0.zip` — datapack стены, 32 ворот и санитарных волн;
- `SHA256SUMS.txt` — контрольные суммы обоих файлов.

CI дополнительно проверяет, что внутри готового JAR находится расширенная точка входа `ru.impuls.core.ImPulsCoreV11Plugin` и `plugin.yml` действительно имеет версию `1.2.0`.

## Что входит в v1.2.0

- физическая внешняя стена примерно 2000×2000 и ровно 32 ворот;
- автоматическое открытие/закрытие ворот и ночные волны санитарной зоны;
- SQLite-профили и аудит экономики;
- динамическая страховка инвентаря на одну обычную смерть;
- гильдии, роли, казна и согласованные сбалансированные войны;
- максимум 10% денежной казны за победу в войне, без захвата редких предметов;
- защищённые участки 32×32, расширение по рангу и атомарная продажа земли;
- VIP-участки 96×96 и изолированный VIP Creative с восстановлением обычного инвентаря;
- временная 24-часовая защита контейнеров вне приватов;
- освобождение обычных/VIP участков после 60/120 дней неактивности;
- отдельные подземелья рангов H–SSS+ на 5–10 этажей с отдельными сессиями инвентаря;
- платный VIP-полёт с отключением в бою/подземельях/войнах;
- городские ивенты и мини-игры;
- внешние шахты/тайники/ресурсные точки;
- изменённые стартовые зоны Нижнего мира и Края;
- исследование лесов, полей, гор, зимних, тропических, морских и других регионов с наградами.

## Исходная datapack-база

Восстановленный v0.9.0 хранится Base64-частями в `archives/`. CI сначала собирает исходный ZIP и требует точное совпадение SHA-256 `1329b8c2181b688eda67a688b7a0a96714769173ac682633363645eeb78f27ae`; только после этого разрешается сборка релиза.

## Проверка сборки

Неуспешный CI не считается релизом. Для v1.2.0 должны пройти: восстановление v0.9.0 → генерация datapack → статическая валидация → упаковка datapack v1.2.0 → Maven → проверка JAR/entrypoint → SHA256 → GitHub artifact.
