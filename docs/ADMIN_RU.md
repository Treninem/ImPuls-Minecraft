# Администрирование ImPuls

## Datapack
- `/trigger impuls_menu` — профиль/меню.
- `/trigger impuls_quest` — ежедневное задание.
- `/trigger impuls_claim` — получить награду задания (старое имя trigger из datapack).
- `/trigger impuls_rankup` — повышение ранга.
- `/trigger impuls_insure` — страховка datapack-уровня.
- `/trigger impuls_spawn` — возврат на площадь.
- `function impuls:admin/wall/start` — построить стену поэтапно.
- `function impuls:admin/wall/status` — статус стены.
- `function impuls:admin/wall/cancel` — остановить очередь строительства.
- `function impuls:city/gates/open_all` / `close_all` — аварийное управление всеми воротами.

## Plugin `/impuls`
- `status`, `insure`;
- `claim buy`, `claim vip`, `claim info`;
- `guild create|invite|accept|leave|deposit|info`;
- `vip creative`;
- `fly`.

Права: `impuls.admin` — администрирование, `impuls.vip` — VIP-механики.
