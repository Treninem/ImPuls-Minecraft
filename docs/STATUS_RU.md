## Нельзя считать проверенным без MineKeep runtime

До фактической установки нельзя утверждать, что полный сервер готов к публичному запуску. На MineKeep необходимо проверить:

- Paper старт без runtime-ошибок;
- фактический результат застройки на существующем рельефе;
- все 32 ворот на живом мире;
- сохранность существующих построек после строителей v1.3;
- Java и Bedrock вход в один мир;
- VIP/рынок/мини-игры на реальные дюпы и потери;
- войны/подземелья с несколькими игроками;
- restart recovery с активными игровыми сессиями;
- полный backup/restore мира средствами хостинга;
- реальные TPS/RAM на текущем лимите MineKeep.
